# Phase report template

1. Phase, completeness and scope restrictions; source access limitations up front.
2. Checkout HEAD/branch/reference comparison, initial changes and final changed paths; artifact identity.
3. Source coverage ledger: every page/section/date, functional links, ambiguous examples/inaccessible content and denominator.
4. Compact full behavior inventory by module: stable IDs, syntax/aliases/modifiers/defaults/permissions/chat types/standalone-child applicability, status/path/test evidence and owning phase.
5. Baseline commands/versions/exit codes/pass/fail/skip/deselected/unrun counts and disposable services.
6. Findings: severity, exact evidence, reproduced versus static inference, impact and regression acceptance.
7. Concrete services/contracts/schema/index/tenant/event precedence/cache/job/compatibility/federation/privacy/locale/API blueprint.
8. Decisions, all open dependencies, exact next-phase recommendations and acceptance tests.
9. Explicit incomplete items and required outside action; no whole-project parity claim.
10. Self-contained relevant report content inline, not only links/hashes. End with the mandated stop sentence.
